# Aether Matrix v1.0.0-rc.1 — Piano Studio

This candidate integrates local, genuinely trained piano composition and expressive performance into the metallic AU/VST3/standalone application. A native sampled piano renders matching 24-bit WAV and editable MIDI from one canonical performance. Inference is offline, in bounded helpers, with cancellation and verified atomic take handoff. No Python ML runtime is needed by the app.

**This is a release candidate, not a stable production release.** Musical consistency, commercial model/output rights, real DAW stress sessions and clean-machine distribution acceptance remain unqualified. The model cards' Apache labels do not settle all listed corpus rights. Optional weights and samples are not bundled. No claim of commercially cleared music or neural waveform generation is made.

## Use

- macOS 14+: installer includes universal AU/VST3 and standalone app. Generative inference targets Apple Silicon; Intel Matrix Synth uses hybrid synthesis.
- Windows 10/11 x64: VST3 installer. Windows native inference and real hosts need separate performance qualification.
- Installers are unsigned; Mac bundles are ad-hoc signed, not notarized. Do not disable system security globally.
- Read the repository README's **First use and optional assets** instructions. Explicitly acquired, hash-pinned assets total about 1.96 GB; retain at least 3 GiB free after acquisition. Select their common parent folder in Piano Studio.
- Generate, audition and drag a take into a DAW. Edit its MIDI, export a compatible single-piano file and import it for direct re-rendering. Instrument credits accompany audio.

## Engineering changes

- Embedded fixed Pianist architecture with original verified BF16 weights; sequential encoder/decoder lifetime and native cached inference.
- Feasible cumulative tempo-constrained expression, with retained probability mass and boundary corrections reported honestly.
- Native composition helper verifies pinned model hashes before ONNX parsing.
- MIDI binary prevalidation, physical-time-aware event import and stable high-tempo roundtrips.
- Immutable in-memory audition, precomputed resampling and allocation/deletion guards on the callback.
- Bounded subprocesses, no shell, minimal inherited environment/handles, parent-death recovery and cross-instance job admission.
- One-millisecond smooth per-voice sample boundary fades prevent aligned sample-start/EOF jumps without ducking sustained notes.
- Same original Matrix parameter identifiers; arbitrary ONNX loading in the DAW removed in favour of the verified bundled reference.

## Known limits

Composition may be repetitive, and some control/seed combinations exceed the expressive model vocabulary and are explicitly rejected. Studio audition follows its own clock, does not play incoming live MIDI through the recorded piano, and does not restore takes/resources with DAW projects. Save exports with your session. Its piano roll displays notes; editing takes place in your DAW.

Numerical, event, audio-format and synthetic callback checks are engineering evidence, not a producer listening approval or audio-device dropout guarantee. See `docs/v1/READINESS.md`, `docs/v1/stage3-evidence.json` and `docs/RELEASE_REVIEW.md` for measured scope and remaining stable-release gates.
