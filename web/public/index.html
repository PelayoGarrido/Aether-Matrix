Release notes & checksums ↗

Before you press play.

How do I install it on macOS?+

Open the downloaded .pkg and follow the installer. If macOS blocks it, go to System Settings → Privacy & Security → Open Anyway, then reopen the installer. Close your DAW before installing and rescan plugins afterward. Administrator permission is required.

This preview is ad-hoc signed, not notarized. Host validation is still in progress; approval of the installer alone does not guarantee every DAW will accept the plugin.

What about Windows?+

Download the Windows installer above and run it to install the x64 VST3 plugin. If SmartScreen offers an override for a build you trust, use More info → Run anyway. This is a preview build; real DAW validation remains in progress.

Which DAWs does it work with?+

AU is intended for Logic Pro on macOS. VST3 is intended for FL Studio, Ableton Live and REAPER. These are target hosts. Installation, scanning, automation and drag-and-drop still require real host testing on each platform.

Does it export audio stems?+

It exports a stereo audio master and a Type-1 MIDI file with tempo, chords, bass and lead tracks. It does not export separate audio stems. Offline renders use the hybrid synth; the ONNX layer is for live playback.

Can I use it or contribute?+

Yes. The source is available under AGPL-3.0-or-later. The license covers the software; your own musical output remains yours. Bug reports, code and host test results are welcome on GitHub. See the repository for the full license and contribution guide.
