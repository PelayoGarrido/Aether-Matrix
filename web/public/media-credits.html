Audio example

The MP3 is a compressed copy of an actual four-bar Aether Matrix hybrid-engine WAV export: A natural minor, 120 BPM, matrix X 0.30 / Y 0.67, density 55%, tension 30%, contour 50%, space 38%. It illustrates this setting and does not represent a trained neural model.

Models & preview status

The included ONNX decoder is a deterministic sine-basis reference, not trained RAVE. Optional trusted compatible models run locally at 48 kHz on Apple Silicon and Windows x64; Intel uses hybrid synthesis. Real DAW validation remains in progress. See the model contract and release notes.
